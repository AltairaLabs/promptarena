Each guide covers one task, with the commands to run and how to check the result.

- [Install PackC](/packc/how-to/install/): install `packc` with npm, Homebrew, `go install` or a release archive.
- [Compile packs](/packc/how-to/compile-packs/): compile an arena config, or one prompt file, into a pack.
- [Validate packs](/packc/how-to/validate-packs/): check a pack locally, before each commit and in CI.
- [Organize pack files](/packc/how-to/organize-packs/): lay out configs and packs by environment, feature or version.
- [CI/CD integration](/packc/how-to/ci-cd-integration/): compile and validate packs in GitHub Actions, GitLab CI and other CI systems.
